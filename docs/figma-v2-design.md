## 원칙

- **디자인 일치가 먼저.** 백엔드 API가 아직 없는 기능도 화면은 만들고, 목업·화면 안에서만 동작·비활성으로 둔다. 아래 [목업 처리](#목업-처리-백엔드-연결-필요)에 모았다.
- 이미 동작하던 흐름(회의 생성, 회의 진행, 회의록 저장)은 깨지지 않게 기본값으로 이어 둔다.
- 색·간격·글자는 `nep!nep!_css` 토큰을 그대로 쓴다 (Figma 변수와 이름이 같다).

## 섹션별 변경

### 04 회의 생성 (`MeetingCreatePage`)

- 별도 페이지 → **폴더 화면 위 560px 모달**. 정보 수정은 회의 대기 화면 위에 같은 모달로 뜬다.
- 입력: 프로젝트 폴더(드롭다운) · 회의명 · 회의 날짜(새 `DatePicker`) · 시작 시간(30분 단위 목록) · 회의 길이 칩(30분/1시간/1시간 30분/직접 입력 → 종료 시간 목록) · 참석자(선택) · 장소(선택).
- 안건·회의록 작성자 입력은 모달에서 뺐다 (대기 화면에서 정한다).
- 닫기 확인 창: [나가기] / [계속 작성하기], Esc는 계속 작성.

### 05 회의 대기 (`MeetingWaitingPage`)

- 레이아웃: 접힌 메뉴 + 상단 바(뒤로·회의명·참여자 얼굴 / 준비 상태·회의 시작하기) + 본문 + 오른쪽 패널(참여자 · 회의록 설정 · 사전 자료).
- 새 `AgendaBoard`: 안건 **보기 모드 / 수정 모드**(그 자리에서 제목·결정할 사항 고치기, 끌어서 순서 바꾸기, 저장 안 하고 나가기 확인). 남은 안건은 체크하면 바로 추가 + [되돌리기] 토스트.
- ⋮ 메뉴: 회의 정보 수정 / 회의 삭제.
- 새 `MemberPickerMenu`: 작성자·참여자 고르기 (얼굴·이름·이메일·체크·안내 문구).
- 사전 자료: 카드 목록 + 끌어다 놓는 업로드 창(`MeetingMaterials`), 올린 뒤 [되돌리기].

### 06 회의 중 (`MeetingRoomPage`)

- 3단: 왼쪽 `AgendaNav`(오늘의 안건 진행) · 가운데 `AgendaFocus` · 오른쪽 실시간 전사 / 내 도우미 탭. 아래 떠 있는 `RecordingBar`.
- 결정 카드: 결정(초록) · 지금 이야기 중(보라) · 미결(주황) · 논의 전(점선), ⋮ 메뉴(결정으로 확정 / 결정 내용 수정 / 근거 발언 보기), 카드 안 수정 폼.
- "14:12부터 N분째": 그 안건으로 분류된 첫 전사 줄부터 계산.
- 알림 줄(`RoomBanner`): AI 일시 중단 · 인터넷 끊김 · 녹음 멈춤 · 예정 시간 초과. 소리 없음 안내(`SilenceNotice`).
- 녹음 바: 일시정지 중 N분째 + [다시 시작], "+N분 초과", ⋯(나가기).
- 다시 만든 창: 새 안건 제안 · 주제 이탈 · 결정 근거(`EvidencePanel`) · 안건 추가 · 나가기 · 회의 끝내기.
- 할 일: 표 모양(`TodoList variant="table"`, 담당자·기한 칩).
- 내 도우미(`ChatPanel`): "나만 보여요" 소개 · 추천 질문 칩 · 둥근 입력칸.
- 용어 감지(`TermText`, `termGlossary`): 전사 속 용어를 파랗게, 마우스를 올리면 뜻 카드와 [더 묻기], 탭에 "용어 N".
- 작성자가 아닌 참석자: 상단에 "보기 전용 · 회의록 작성자 OOO".

### 07-08 회의록·양식

- 회의록 편집(`MinutesEditorPage`): 다운로드를 상단 바 드롭다운(PDF / Word)으로, 회의 정보 줄은 회색 작은 글자 + [변경], 서식 도구 막대, 양식 변경 확인 창.
- 오른쪽(`MinutesSidePanels`): 안건 고르기(상태 표시 · 1/N 이동) → 안건 요약 · 주요 의견 · 결정현황(근거 발언 보기 → 전사 줄 강조) · 아직 합의되지 않은 부분, 전사 기록 접기/펼치기.
- 양식 목록(`TemplateListPage`): 기본 양식 / 내 양식 미리보기 카드, 즐겨찾기 별, ⋮(수정·복제·삭제), 정렬, 바로 복제 + [수정하기] 토스트, 양식 가져오기 창(`TemplateImportModal`).
- 양식 편집(`TemplateEditorPage`): 왼쪽 항목 목록을 체크박스 → "+ 추가 / ✓ 추가됨" 줄로.

로컬 통합 환경을 띄우며 infra 쪽에서 찾은 문제 (이 브랜치에는 없음, infra에 따로 반영 필요):

- `integration/localstack/*.sh`가 실행 권한 없이(100644) 올라가 있어 macOS에서 SQS 큐가 안 만들어진다 → `git update-index --chmod=+x`.
- 최신 ai-service 이미지는 `MINUTES_LLM_PROVIDER`가 꼭 필요하다 (시험용 `fake`). compose 기본값이 비어 있어 회의록 초안 요청이 503.
- `seed_demo.py`의 `internal()`이 meeting-service 컨테이너의 `curl`을 쓰는데 이미지에 없다.
- 지금 백엔드 이미지에 사전 자료(`/materials`)·내 도우미(`/chat`) API가 없어 404.
